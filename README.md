# SpireX Foundation Website

A modern, clean, and responsive website developed for **SpireX Foundation** by the SpireX Foundation Interns.

The website is designed to present the foundation's mission, initiatives, programs, projects, and other important information through a professional and user-friendly digital experience.

## 🌐 About the Project

The **SpireX Foundation Website** is a collaborative frontend development project created by the interns of SpireX Foundation.

The primary focus of the project is to build a **neat, clean, modern, responsive, and professional website** that reflects the identity and vision of the foundation.

## ✨ Key Features

* Modern and professional UI design
* Fully responsive across desktop, tablet, and mobile devices
* Clean and structured page layouts
* Consistent typography and branding
* Interactive navigation and UI components
* Responsive sections and reusable components
* Smooth hover and transition effects
* User-friendly interface
* Optimized structure for maintainability

## 🎨 Design & Branding

The website follows a premium and professional visual identity.

| Element       | Design                       |
| ------------- | ---------------------------- |
| Primary Color | Navy Blue                    |
| Accent Color  | Gold                         |
| Background    | Cream / Soft White           |
| Typography    | Poppins                      |
| Design Style  | Modern, Clean & Professional |

### Color Usage

* **Navy Blue** – Primary sections, navigation, headings, and major UI elements
* **Gold** – Buttons, highlights, icons, and important call-to-action elements
* **Cream** – Selected background sections and visual separation
* **White** – Cards and clean content areas

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layouts, responsiveness, and animations
* **JavaScript** – Interactive functionality
* **Google Fonts** – Poppins
* **Git** – Version control
* **GitHub** – Collaboration and project management

The website is built with a responsive-first approach to provide a consistent experience across:

* Desktop
* Laptop
* Tablet
* Mobile devices

Flexible layouts, CSS media queries, and responsive components are used to adapt the website to different screen sizes.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone <repository-url>
```

### Navigate to the Project

```bash
cd spirex-foundation-website
```

### Run the Website

Open `index.html` directly in your browser or use **VS Code Live Server** for development.
